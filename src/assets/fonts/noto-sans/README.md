# Noto Sans

Noto Sans Regular and Bold, version 2.015, from the Noto project
(https://github.com/notofonts/latin-greek-cyrillic, files as published at
https://github.com/notofonts/notofonts.github.io/tree/main/fonts/NotoSans/hinted/ttf).

Licensed under the SIL Open Font License, Version 1.1. The licence is in `OFL.txt` beside this file. The files are
unchanged.

ProfitShare uses them only for a budget PDF with letters Helvetica lacks (Greek, Cyrillic, Vietnamese, Polish and the
rest of Latin). The app fetches them when such a PDF is made, and the PDF carries only the letters it uses.
